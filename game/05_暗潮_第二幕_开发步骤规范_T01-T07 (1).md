# 《暗潮》第二幕开发文档 05：开发步骤规范（T01–T07）

> 第二幕内部名称：**黑补母**  
> 核心结构：**民俗调查 → 现实调查 → 两条线汇合**。  
> 第一幕已有的桌面、微信、浏览器、记事本、资源管理器、照片查看器全部优先复用。

## 总体流程

```text
T01 搜索失效
↓
T02 桥头老人：“黑捕木”→“黑补母”
↓
T03 县图书馆：找到《补母志》
↓

↓

```

# T01：互联网搜索失效

## 目标
延续第一幕“遇到问题就搜索”的习惯，但第一次明确告诉玩家：普通互联网无法解释“补”和双S。

## 前置状态
```text
FLAG_A1_SS_FOUND
FLAG_A1_BU_FOUND
FLAG_A1_MISSING_CASE_SUSPICIOUS
```

## 玩家操作
支持模糊关键词：
- 鸡头岭 补
- 鸡头岭 神像
- 补 神像
- 双S 十字
- A.W 鸡头岭
- 鸡头岭 石庙

## 页面要求
搜索结果混入：
- 进补文章
- 补品广告
- 补课机构
- 修补服务
- 鸡头岭旅游攻略
- 同名地点
- 摄影帖子
- 无关地方新闻
- 泛符号百科

本阶段**不得出现能直接解释“黑补母”的现代网页**。

## 记事本
自动生成模糊判断：

> 网上几乎找不到有用的信息。  
> 这种东西，也许只有当地人才知道。

## Flag
```text
FLAG_A2_SEARCH_BU_ATTEMPTED
FLAG_A2_SEARCH_SS_ATTEMPTED
FLAG_A2_WEB_SEARCH_FAILED
FLAG_A2_OFFLINE_RESEARCH_NEEDED
```

## 防卡
- “补”线索保持待确认状态。
- 浏览器历史保留第一幕鸡头岭调查。
- 长时间没有动作时，记事本补充：“这个词太普通了。”

## 完成标准
玩家理解：**要换一种调查方式。**

# T02：桥头老人——“黑捕木”口述辨识

## 目标
正式引入“黑补母”名称，但保留地方口音和口述信息的不确定性。

## 场景
县城桥头/路边休息区域。多个老人聊天，没有任务头标。

## 玩家操作
- 与不同老人交谈
- 询问鸡头岭
- 展示破庙照片
- 展示“补”字照片
- 展示残缺塑像照片

对话中混入大量生活性噪音：
- 山路情况
- 年轻人徒步
- 村里旧闻
- 邪祟说法
- “吃什么补什么”

## 核心触发
指定老人看到正确照片后，说出带方言口音的：

> “黑捕木。”

系统**不能自动纠正**。

## 轻量谜题
记事本记录：

```text
hei bu mu？
黑 / 嘿
捕 / 补 / 埔
木 / 母 / 墓
```

玩家结合第一幕石碑上的“补”，还原：

```text
黑补母
```

## 成功反馈
- 生成正式词条：`黑补母`
- “补”与“黑补母”建立关联
- 老人补充“以前县志里好像写过”

## Flag
```text
FLAG_A2_ELDER_PHOTO_SHOWN
FLAG_A2_HEIBUMU_AUDIO_HEARD
FLAG_A2_HEIBUMU_NAME_SOLVED
FLAG_A2_COUNTY_RECORD_HINT_KNOWN
```

## 防卡
- 错误多次后锁定中间字“补”。
- 老人再次强调“吃什么补什么”。

## 完成标准
玩家获得：
- 黑补母
- 吃什么补什么
- 县志可能有记录

# T03：县图书馆——地方志检索

## 目标
通过真实“查资料”找到黑补母记载。

## 场景氛围
- 老旧县图书馆
- 泛黄地方志
- 安静阅览区
- 暗淡灯光
- 纸张翻页声

## 玩家操作
1. 查看地方志目录。
2. 根据“鸡头岭 / 民俗 / 黑补母”缩小范围。
3. 找到对应卷册。
4. 翻页。
5. 找到《补母志》。

## 目录噪音
必须存在：
- 地理沿革
- 山川河流
- 风俗
- 祠庙
- 乡贤
- 农业
- 灾害
- 方言
- 地方传说

## 核心信息
《补母志》中玩家获得：
- 黑补母与“补缺”
- “以有余补不足”
- 食用某种东西以获得对应能力
- 民间供奉方式

## 交互
- 翻页
- 放大
- 书签
- 关键词标记
- 摘录到记事本

## Flag
```text
FLAG_A2_LIBRARY_ENTERED
FLAG_A2_LOCAL_GAZETTE_FOUND
FLAG_A2_BUMUZHI_FOUND
FLAG_A2_BUMU_RULE_BASIC_KNOWN
```

## 防卡
目录可逐步给出弱视觉引导，但不能直接高亮答案。

## 完成标准
玩家理解黑补母的表层规则：

> **“缺什么，就用某种东西补什么。”**

# T04：三篇志异——规则归纳谜题

## 目标
让玩家自己推导：

> **“补”进来的可能不只是能力，也会夹带来源者的行为、记忆或身份特征。**

## 三篇内容

### 石工
- 缺失：手指功能
- 进食：山鸡足
- 获得：手指恢复
- 异变：出现类似山鸡的行为

### 六儿
- 缺失：识字/智力
- 进食：来源不明的肉
- 获得：识字能力
- 异变：出现“沈”姓他人的记忆/身份痕迹

### 哑女
- 缺失：声音
- 进食：鸟
- 获得：可以发声
- 异变：发出已经消失的地方鸟鸣

## 玩法
玩家阅读后进入资料整理界面：

```text
人物 | 缺失 | 进食 | 获得/异变
```

将散乱卡片拖入正确位置。

## 成功反馈
不出现“解谜成功”。

完成后缓慢显示：

> “补来的东西，终究不是自己的。”

> “黑补母只管补，不管补进来的究竟是谁的。”

## 记事本
只新增一个问题：

> **小A缺什么？**

禁止直接告诉玩家“小A吃过什么”。

## Flag
```text
FLAG_A2_TALE_01_READ
FLAG_A2_TALE_02_READ
FLAG_A2_TALE_03_READ
FLAG_A2_TALES_SORTED
FLAG_A2_TRANSFER_RULE_INFERRED
```

## 防卡
- 卡片只允许进入对应类别列。
- 多次错误后锁定一个明显条目。
- 随时可重开原文核对。

## 完成标准
玩家形成未证实假设：**“补”会携带来源者的一部分。**

# T05：回到高中——小A变化、启明与双S

## 目标
让“民俗线”重新接回小A的现实经历。

## 过渡
小月微信联系玩家。

聊天中加入：
- 三人旧合照
- 初高中照片
- 普通玩笑
- 聚会照片
- 小A旧照
- 小月的日常内容

这些内容必须可看，但不全部作为关键线索。

## 高中场景
可探索：
- 校门
- 走廊
- 小A旧教室
- 小月旧教室
- 厕所方向
- 消防栓
- 光荣榜
- 老师办公室
- 宣传栏

## 消防栓伏笔
必须出现，但：
- 不标红
- 不写入记事本
- 不提示可疑
- 不作为当前谜题

它只负责为第三幕藏笔记做视觉记忆。

## 老师信息
玩家获得：
- 小A高二休学两个月
- 回校后明显变安静
- 几乎只学习
- 与同学关系疏远
- 成绩快速提升

## 光荣榜
玩家在大量毕业生中找到王澳。

显示排名变化：

```text
600 → 400 → 300 → 130 → 88 → 53 → 20
```

同时看到：

> “感谢……启明青少年成长中心两个月来对我的教育和培养……”

## 学霸笔记
玩家查看旧学习资料，在页边再次发现**双S**。

## 双S比对
允许：
- 并排查看
- 放大
- 半透明重合

与第一幕山洞双S高度一致后，记事本生成：

```text
双S
├── 鸡头岭
└── 小A / 启明
```

## Flag
```text
FLAG_A2_SCHOOL_ENTERED
FLAG_A2_FIRE_HYDRANT_SEEN
FLAG_A2_LEAVE_OF_ABSENCE_KNOWN
FLAG_A2_SCORE_CHANGE_KNOWN
FLAG_A2_QIMING_NAME_FOUND
FLAG_A2_SCHOOL_SS_FOUND
FLAG_A2_SS_MATCH_CONFIRMED
```

## 防卡
- 光荣榜通过构图自然引导，不做像素级找物。
- 若忽略学霸笔记，小月/老师可提到学校以前展示过他的笔记。

## 完成标准
玩家建立：

```text
休学两个月
↓
性格改变
↓
成绩暴涨
↓
启明
↓
双S与鸡头岭一致
```

# T06：启明线上调查——官方宣传与旧论坛

## 目标
制造明显的信息冲突：

```text
官方：成功 / 感恩 / 孝顺 / 成绩提升
VS
亲历者：暴力 / 禁闭 / 奇怪饮食 / 广播 / 意识异常
```

## 支持搜索
- 启明青少年成长中心
- 启明 青少年
- 启明 改造
- 启明 戒网
- 启明 投诉
- 启明 黄子山
- 启明 钟子月

## 官方页面
包括：
- 旧官网
- 地方媒体宣传稿
- 家长感谢信
- 成功案例
- 军事化管理
- 孝道教育
- 两个月改变孩子
- 提高成绩
- 戒除游戏依赖

## 旧论坛
较后位置出现旧论坛/贴吧式页面。

内容包括：
- 被强行送入
- 禁闭
- 挨打
- 恶心的肉
- 酸味/油脂味
- 广播
- 意识模糊
- 突然恢复正常
- 想回去看看

## 用户名对应谜题
官方成功案例：

```text
黄子山
钟子月
```

论坛昵称：

```text
黄山
月子
```

玩家判断可能为同一人。

## 后续搜索
继续搜索实名后，发现：
- 黄子山后来失联/下落不明
- 钟子月后来出现精神异常并失踪或离家

作用：把案件从“小A个人异常”扩大为“多名学员异常”。

## Flag
```text
FLAG_A2_QIMING_OFFICIAL_FOUND
FLAG_A2_QIMING_TESTIMONIALS_READ
FLAG_A2_QIMING_FORUM_FOUND
FLAG_A2_HUANG_MATCH_INFERRED
FLAG_A2_ZHONG_MATCH_INFERRED
FLAG_A2_OTHER_CASES_ABNORMAL
```

## 防卡
- 只看官方页面时，记事本提示：“搜索结果几乎都是宣传材料。”
- 搜索“投诉/经历/论坛”时提升旧论坛排序。
- 成功案例姓名支持点击复制。

## 完成标准
玩家判断：**启明并非普通高压教育机构，而且异常不止发生在小A身上。**

# T07：宣传视频逐帧调查与幕末收束

## 目标
完成两条调查线汇合：

```text
黑补母 / 鸡头岭
+
启明 / 小A
↓
同一地点
```

并为第三幕“再次进山找启明”提供明确目标。

## 触发内容
玩家在旧宣传资料中找到视频。

视频表面内容：
- 创始人/教师讲话
- 科学教育
- 行为矫正
- 传统文化
- 军事化管理
- 户外活动
- 山区环境

## 播放器交互
必须支持：
- 播放/暂停
- 拖动进度条
- 前后跳转
- 单帧或近似逐帧
- 截图
- 放大截图

## 核心发现一：破庙
某个短暂镜头背景中出现熟悉的石质建筑。

玩家打开第一幕破庙照片进行比对，确认轮廓一致。

## 核心发现二：双S
视频或宣传素材角落再次出现双S。

## 记事本最终结构
```text
鸡头岭
├── 黑补母
├── 破庙
├── 双S
└── 小A失踪

启明
├── 小A曾接受改造
├── 学霸笔记双S
├── 多名异常学员
└── 宣传视频出现鸡头岭破庙
```

最终生成：

> **启明曾经就在鸡头岭附近。**

## 幕末微信
小月和玩家商量第二次进山。

可包含：
- 天气
- 徒步准备
- 小月发登山鞋/装备照片
- 约定时间

不要出现“进入第三幕”按钮。

## 黑屏旁白
> 第一次进山的时候，我只是想找一个失踪的人。  
>
> 第二次，我已经知道自己在找什么了。  
>
> **启明。**

背景音：
```text
键盘声 → 淡出 → 雨声 → 风声/树叶
```

## Flag
```text
FLAG_A2_PROMO_VIDEO_FOUND
FLAG_A2_PROMO_VIDEO_WATCHED
FLAG_A2_TEMPLE_FRAME_FOUND
FLAG_A2_VIDEO_SS_FOUND
FLAG_A2_QIMING_LOCATION_INFERRED
FLAG_A2_SECOND_TRIP_PLANNED
FLAG_A2_COMPLETE
```
