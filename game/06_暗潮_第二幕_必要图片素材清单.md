# Q. 第二幕素材验收原则

每张正式素材导入前检查：

- [ ] 是否明确对应 T01–T07 中至少一个阶段
- [ ] 是否有唯一素材 ID
- [ ] 是否已经登记用途
- [ ] 是否存在可复用旧素材
- [ ] 是否需要多个状态版本
- [ ] 是否会被放大 / 裁切 / 对比
- [ ] 人物身份在不同图片中是否一致
- [ ] 是否过度“恐怖化”导致失去写实感
- [ ] 是否把本应由玩家发现的线索画得过于明显

最终原则：

> **第二幕图片的目标不是告诉玩家“这里很恐怖”，而是让大量正常、真实的材料在玩家自己建立联系以后变得恐怖。**
