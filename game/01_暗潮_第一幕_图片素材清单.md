# 《暗潮》第一幕开发文档 01：图片素材清单

> 用途：用于第一幕所有视觉素材的统一规划、制作、命名与替换。  
> 原则：这里只定义“素材分组标题 + 用途”，不展开具体生成提示词。  
> 要求：所有图片素材必须可编号、可替换、可追溯到对应剧情节点。

## A. Windows 11 桌面基础界面素材
**用途：**构建第一幕主交互壳层，保证玩家一进入就是一台真实使用中的电脑。

- 桌面背景图
- 任务栏基础图标
- 系统托盘状态图标
- 窗口控制按钮素材（最小化 / 最大化 / 关闭）
- 应用图标（邮箱、微信、浏览器、资源管理器、照片、记事本等）
- 通知中心 / 弹窗样式素材
- 右键菜单 / 系统菜单样式素材

## B. 微信界面素材
**用途：**承载生活剧情、人物关系、信息触发与部分核心线索。

- 微信主界面框架
- 联系人列表头像组
- 聊天气泡素材
- 语音 / 图片 / 文件消息气泡
- 红点 / 未读提示
- 顶部会话栏
- 图片查看界面
- 文件发送界面
- 聊天背景图（如需）

## C. 邮箱界面素材
**用途：**承载小A关键邮件，以及大量春招、offer、广告、订阅、验证码等无关内容。

- 邮箱主界面框架
- 邮件列表项样式
- 已读 / 未读状态样式
- 发件人头像占位
- 邮件详情页样式
- 附件样式
- 文件夹栏样式（收件箱 / 已发送 / 垃圾箱 / 订阅等）
- 搜索栏样式

## D. 浏览器与搜索结果素材
**用途：**模拟真实互联网调查过程，展示搜索引擎、新闻页、百科页、论坛页、地图页等。

- 浏览器主框架
- 搜索引擎结果页样式
- 新闻网站页面样式
- 百科页面样式
- 地方论坛页面样式

- 搜索建议下拉样式

## E. 资源管理器 / 文件系统素材
**用途：**增强生活真实性，并作为照片、文档、下载内容的承载空间。

- 资源管理器框架
- 文件夹图标

- 文档文件图标

## F. 记事本 / 线索记录素材

- 标记重点 / 待确认样式（如需）

**用途：**增强写实感，避免界面只存在“有用内容”。

- 无关广告图
- 新闻缩略图
- 订阅邮件头图
- 招聘平台邮件头图
- 面试邀请模板图
- offer 通知模板图
- 操作系统通知样式图
- 微信联系人头像批量素材

- 搜索结果缩略图

## 素材设计总原则
1. 不要让所有图片都服务主线。
2. 关键素材必须混在大量正常生活素材中。
3. 微信图片、邮箱头图、新闻配图都应承担“真实电脑”氛围，而不是只承担剧情。
4. 核心线索图必须支持后续放大、查看、编辑或二次引用。
5. 所有素材必须采用统一命名规范，并在开发记录中登记。
