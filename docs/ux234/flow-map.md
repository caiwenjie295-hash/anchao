## 目标调查循环

每段遵循“疑问 → 可读材料 → 玩家观察/对照 → 有证据支持的判断 → 明确行动 → 新疑问”。材料可先读，推论与离开动作分别记录。无关环境观察不作为阶段门槛。当前阶段内可回看；跨阶段回看只读。
