### A1 邮件搜索与现场照片

实现位于 `MailApp`、`BrowserApp` 与 `browserSearchRequest`：合法打开的小 A 邮件只发送一次跨 App 搜索请求；请求不写持久状态，不会把旧 queryHistory 当成新请求。搜索主页按第一幕真实发现显示下一步；干扰文章可回当前搜索任务并保留历史、已读状态。
