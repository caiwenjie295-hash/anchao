# UX-T07-UI-0001 存档兼容说明

当前存档 schema 为 13，读取器接受 schema 1–13。第四幕 A34 阅读进度、章节动作与旧存档门槛保留；UX-T07 的新证据字段在 hydrate 时与旧版完成事实分开处理。

## T06 个案复核

新完成路径把黄子山与钟子月分别记录为有来源的个案复核，记录包含实际查看的来源页和结论。旧的昵称推断标记不再作为新主线的实名结论，也不会凭旧 Flag 造出 `reviewedCases`。

旧存档只有在必需资料页和旧版完整完成标记都存在时，才迁移为 `legacyCompletionMigrated`；schema 12 及以上仅保留原有、经同样事实检查的迁移标记。界面可把它显示为已恢复的历史完成进度，玩家不必重复已完成的章节，同时不会虚构新的来源配对、结论选择或复核时间。缺少有效前缀的裸未来 Flag 不会升级为已完成。

## T07 图片比较

schema 13 将每个成功比较帧与 `comparisonFeatureIdByFrameId` 中的依据一起保存，并在 hydrate 时确认该帧支持外景匹配且依据正是支持的形态。错误帧、错误依据、缺失依据或不一致记录会从比较事实中清除，同时清除依赖它的寺庙外景、地点推断、二次出发与完成状态。

schema 12 成功比较可能没有新字段。若其原存档仍有成功比较 Flag、被捕获的有效外景帧及合法帧进度，迁移可补回唯一受支持的匹配依据；schema 1–11 的有效旧比较按保留的旧成功事实迁移。无效或单独伪造的 Flag 不足以通过检查。新的保存 API 会同时记录依据映射，避免生成 schema 13 的不完整比较事实。

## 其他保留边界

schema 11 的 A34 第三幕合法退出与第四幕阅读迁移不因 schema 13 改动回退。未证实的结局信息仍不被迁移逻辑补写。上述迁移由当前存档定向测试及 A34 已批准基线的独立往返检查覆盖；没有运行所有历史 schema 与所有字段损坏组合的全排列测试。
