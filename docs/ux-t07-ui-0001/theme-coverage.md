# UX-T07-UI-0001 白灰主题覆盖与对比度抽样

应用界面主体使用白、灰和深色文字；共用强调色集中在 `src/styles.css :root`：`--ui-accent: #165dcc`、`--ui-accent-soft: #eaf2ff`。照片保留原始色彩，调查场景的剧情黑场继续使用深色背景。主题按既有语义组件规则实现，不靠末尾的大范围覆盖来改变状态色。

| 实际页面/状态 | 检查范围 | 最小对比度 | 结果 |
|---|---|---:|---|
| Browser 十类来源页 | 标题、正文、元信息、图片说明 | 4.624:1 | PASS |
| T06 个案复核 | 普通、禁用、错误反馈 hover、已记录 | 6.146:1 | PASS |
| 邮件应用 | 普通星标、已选星标、工具禁用等抽样状态 | 5.443:1 | PASS |

这些数字来自主审真实浏览器 computed-style 抽样，全部目标样本通过且无 pageerror。此次抽样不表示穷举了全站每个控件、所有焦点组合、背景图像上的每一个像素，或所有图标的每种状态。学校照片主图、Act3/Act4照片素材和剧情黑场是有意保留的媒体/剧情表面，不属于白灰网页面板。
