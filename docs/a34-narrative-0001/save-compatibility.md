# 第四幕存档兼容（N4）

验证日期：2026-10-01。新存档使用 schema 11，以 `completedNarrativeSectionIds` 和 `completedNarrativeActionIds` 记录阅读章节与有剧情意义的动作。迁移从旧题目、材料和场景访问记录推导已有事实；旧题 ID 不会被补写成已解。

| 旧记录 | 保留或推导的事实 | 完整章节的额外条件 |
| --- | --- | --- |
| 两位收件人的邮件检查、两个账号均已解锁 | 迁移为 T02 登录动作；实际账号内容仍在阅读器成功登录后解锁 | T02 完成标记与有效登录动作都须存在 |
| `viewedWakeMail` 且邮箱已解锁 | 保留 T04“邮件已打开”动作，即使尚未答旧 P09 | 完成 T04 还须旧 P09 记录 |
| 有效的后段访问前缀到达 `A4_T08_ARCHIVE` | 保留 T08“档案已打开”，即使尚未答 P18 或访问镜子/厨房 | 完成 T08 还须 P18 和厨房节点记录 |
| 生日节点与后段节点 | 仅在对应章节已到达时保留；后段节点按章节顺序及前置事实验证 | T05 完成须 P11 且生日到达 `taken`；不从单个高阶段编号倒推全部章节 |
| 广播周期与后段访问记录 | schema 10 之前，旧 P13 可证明早晚广播已确认；有效访问前缀依前置条件保留 | T06 完成还须禁闭节点；未来或不可达节点会从访问记录中移除 |
| T09 包装步数、广播序号、藏笔记/离门节点 | 仅当藏笔记和相邻节点的顺序证据有效时保留对应动作；门外动作还要求完整六词广播 | T09 完成须藏好笔记并离开；单独的高广播序号不会授予完成标记 |
| `finalMailOpened` | 保留已打开最终邮件的事实 | T10 完成还须合法前序章节、动作及旧完成标记 |

对 schema 9/10，章节完成标记必须同时有相应旧题、材料或节点证据。缺证据的存档会退回到最早未能证明的章节，保留此前合法进度和已验证的中途动作；不会清空整份进度，也不会把 24 个机械题 ID 批量标为完成。schema 11 则要求章节 ID、完成标记和章节动作门槛相符。再次保存并 hydrate 后保持同一结果。

`src/story/act4/laterFlow.ts` 中的旧题门槛已标记为弃用兼容代码；当前 `Act4Experience` 与兼容入口 `Act4LaterExperience` 都使用同一个阅读器和 `narrativePolicy`。检索 `src` 的非测试运行时代码未发现对 `laterFlow.ts` 的导入，旧题判断不参与新的阅读推进。
