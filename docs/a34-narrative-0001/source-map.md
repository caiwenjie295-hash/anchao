## 2. 提取管线

PDF 正文使用内嵌子集字体（`BCDEEE+SimSun`）与 ToUnicode CMap 映射，
无法直接复制文本。新增 `scripts/extract-novel-text.py`：

- 仅依赖 Python 标准库（`re` / `zlib`）；
- 解析 `ToUnicode` CMap 的 `bfchar` / `bfrange`，把内嵌字体的 CID 还原为 Unicode；
- 按页输出 `===== PAGE n =====` 分隔的纯文本，供逐段取材与人工核对。

```powershell
python scripts/extract-novel-text.py <输出路径.txt>
```

实测可提取 **39 页、123,516 字节**，中文正文完整、标点正常，
例如第 26 页可稳定还原「两个账号密码一样…」「20200419！」等关键段落。

**限制**：行内数字与拉丁字符可能被拆成独立行（如 `2020` / `年` / `4` / `月` / `19` / `日`），
这是嵌入字体按字形定位造成的，**不是原文排版**。正式引用前必须按 PDF 原页视觉核对并合并。

## 5. 三类内容的边界

| 类别 | 存放位置 | 规则 |
| --- | --- | --- |
| 小说原文 | `blocks[].kind === 'novel-excerpt'` | 必须能在 PDF 指定页逐段找到；**不改写原句** |
| 改编衔接 | `blocks[].kind === 'adaptation-bridge'` | 调查者第一人称，连接原文与当下调查，**不得冒充原文** |
| 剧情解释 | 独立 `explanations` 映射 | 「已发生的经历 → 与哪些前文联系 → 仍未确定什么」，绑定 reveal 条件 |
