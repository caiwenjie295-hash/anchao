# UX-PROGRESS-20261003 实现记录

## 功能

`InvestigationProgressProvider` 从当前 `AppState` 派生只读进度，并统一打开右侧原生 `<dialog>`。桌面提示卡、活动应用标题栏、共用调查页头、第一幕现场与第一幕收尾都可打开抽屉；转场展示时入口会被抑制。抽屉默认关闭，使用单一正文滚动区，显示当前目标、下一步、已到达路线、已出现的待查方向和已读/已检视/已记录材料。关闭后焦点回到打开入口。

进度模型直接读取现有 Flag、访问记录、检查记录和叙事完成记录，不写存档或推进阶段。A2 个案材料按实际访问/复核状态分别呈现；A3 路线完成态读取已有阶段完成 Flag 或确认记录，当前路线文字对未读纸片/未取物件使用安全显示名；A4 回顾仅包含已完成篇章，并标明调查者阅读或王澳亲历视角。T07 的完整视频播放不作为当前必做步骤。

桌面提示卡在折叠时常驻显示可执行的下一步。活动应用窗口出现时隐藏浮动卡，并在标题栏显示当前建议，避免遮住窗口控件。无任务指南的现场阶段仍显示当前步骤。`data/task_guides.json` 仅调整既有摘要、步骤标题和提示文案，没有改变记录顺序或完成条件。

## 可访问性与样式

抽屉使用原生 modal dialog 的 Escape、模态背景和焦点约束行为；程序性关闭会将焦点交还给入口。打开抽屉有 200ms 轻量滑入动画，并尊重 `prefers-reduced-motion`。抽屉按钮、桌面进度入口和场景页头入口保持至少 44px 高；窗口标题栏继续使用原有高度。抽屉样式与标题栏/场景入口样式集中在 `src/components/investigationProgress.css`，全局 `src/styles.css` 只改 `.desktop-task-card*` 选择器。

## 验证

定向测试覆盖模型阶段与已知事实、T05 纸片未读时的防剧透投影、T07 可选完整播放、Act3/Act4 交界、Drawer 开闭/焦点/状态只读、桌面无指南阶段和 InvestigationShell 页头入口。JS DOM 测试不证明真实浏览器中的视口布局或原生焦点环；本批由父代理对默认窗口、最大化和窄屏做真实浏览器抽查。
