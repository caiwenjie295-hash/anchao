1. 完成第一幕后，在幕末页选择“回到桌面，继续调查”。
2. T01 复用桌面浏览器，分别搜索“鸡公岭 + 补”和“双 S + 十字”方向；网上无解后转向线下调查。

## 6. 下一阶段：T05 接手范围

权威需求位于 `game/05_暗潮_第二幕_开发步骤规范_T01-T07 (1).md` 的“T05：回到高中——小A变化、启明与双S”。目标是让民俗线重新接回小A的现实经历。

T05 需要实现：

- 小月微信过渡，混入旧照、聚会照与普通生活内容，不把所有照片都做成线索。
- 高中探索：校门、走廊、旧教室、厕所方向、消防栓、光荣榜、老师办公室、宣传栏。
- 老师信息：小A休学两个月、返校后安静疏远、只学习、成绩快速提升。
- 光荣榜：王澳名次 `600 → 400 → 300 → 130 → 88 → 53 → 20`，并出现启明青少年成长中心。
- 学霸笔记中再次出现双 S；支持与第一幕山洞双 S 并排、放大和半透明重合。
- 完成比对后，在记事本建立“鸡公岭 ↔ 小A / 启明”的关联，但不提前实现 T06 调查结论。

T05 规范列出的 Flag：

```text
FLAG_A2_SCHOOL_ENTERED
FLAG_A2_FIRE_HYDRANT_SEEN
FLAG_A2_LEAVE_OF_ABSENCE_KNOWN
FLAG_A2_SCORE_CHANGE_KNOWN
FLAG_A2_QIMING_NAME_FOUND
FLAG_A2_SCHOOL_SS_FOUND
FLAG_A2_SS_MATCH_CONFIRMED
```

必须保留的叙事限制：

- 消防栓只作第三幕视觉伏笔：不标红、不写入记事本、不提示可疑、不作为当前谜题。
- 光荣榜用构图自然引导，不做像素级找物。
- T05/T06 优先复用现有微信、浏览器、照片查看与记事本能力。
- 开发前先冻结 T05 的 phase/stage、存档字段、Flag、笔记和资源 ID；若新增持久化结构，需要设计 schema 3→4 迁移和损坏字段回退测试。
