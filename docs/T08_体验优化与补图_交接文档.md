# 《暗潮》第一幕 T08 体验优化与补图交接

## 交付范围

- 微信联系人列表与消息区独立纵向滚动；切换联系人和新消息出现时自动归底。
- 鸡公岭 G–I 调查外壳改为浅灰，并固定显示“在图片中寻找线索，点击获取线索”。
- 点击热点立即沿用既有 `inspectSceneHotspot` 推进，同时打开瞬时特写层。
- 普通热点复用当前场景背景并按热点中心放大 2.25 倍；有独立资源的热点显示对应图片并渐显。
- 特写支持“关闭特写”、Escape、遮罩关闭、打开后焦点与减少动态。
- 补齐 5 张 1448×1086 RGB PNG，并重建在线/离线产物。

## 关键入口

- 微信滚动：`src/modules/wechat/WechatApp.tsx`、`src/imageAssets.css`。
- 调查主界面：`src/scenes/act1/Act1SceneExperience.tsx`。
- 特写组件：`src/scenes/act1/SceneClueFocus.tsx`。
- 特写测试：`src/scenes/act1/SceneClueFocus.test.tsx`。
- 资源映射：`data/images.json`。
- 原始执行契约：`docs/第一幕_T08_体验优化与补图_并行契约.md`。
