# 图片资源接入

运行中的地点名称统一为“鸡公岭”，原始小说与历史开发文档保留原文。资源 ID 保持稳定。

| 目录／文件 | 使用位置 |
| --- | --- |
| UI_src/UI1.png–UI4.png | 桌面和任务栏应用图标、窗口按钮、聊天文件图标 |
| Wechat_src/Wechat1.png、Wechat2.png | 联系人及聊天头像 |
| 小学合照1.png、初中合照1.png | 小月和同学群的历史消息 |
| 救援队1.png、救援队2.png | 失踪新闻页面 |
| 鸡公岭地图.png | 路线页面；入口至山顶约 7 公里 |
| 鸡公岭入口.png | 入口调查背景 |
| 山洞内整体景.png | 山洞调查背景 |
| A.W刻字黑暗.png | 刻字局部与拍摄后的照片编辑 |
| 石庙外景1.png | 石庙调查背景 |
| 补字碑.png | 石碑调查局部与拍摄照片 |
| 黑补母特写1.png | 残缺塑像调查局部；玩家界面不显示源文件名 |

照片来自 `src/Photo_src`，通过 `data/images.json` 映射；UI 和头像的裁剪区域定义在 `src/data/spriteData.ts`。原始 PNG 不作修改。

现场热点随对应背景重新定位，照片保持 4:3 比例。双 S 使用原有交互层，在照片调整达到条件后显示并由玩家主动检查。

林间小路、溪边及未提供图片的生活聊天内容仍保留原型占位。音频尚未接入。

运行 `npm run build:offline` 后，根目录 `暗潮.html` 内嵌全部图片，可双击打开，无需服务。当前文件约 47 MB。
