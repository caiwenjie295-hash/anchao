# 品类基准与品质评分卡

> 用途：为《暗潮》定义「对齐已发售 Steam 独立解谜/叙事推理游戏」的**可验证**验收标准。
> 与实现解耦，可独立用于评审 Luna 的 UX-234-REWORK 及后续任一工单。
> 证据来源为已发售作品的开发者公开表述、平台指南与玩家实测记录；无法取证处已在 §6 标注。

---

## 1. 品类结论（先看这个）

伪桌面 / 伪聊天软件式的文字推理游戏是**已被验证可发售**的类型：
《疑案追声》(Unheard, 2019, 好评 96%，26161 份中文评价)、《The Roottrees are Dead》(2025, 好评 96%)。
中文市场也有《橘猫侦探社》(微信小游戏) 这一「虚构聊天软件承载全部剧情」的先例。

但该品类的**质量上限不由叙事或美术决定，而由一件事决定**：

> **玩家的推理是否可以被「把所有文件都点一遍」穷举破解。**

《疑案追声》玩家社区对这一失败模式有非常精确的表述：
> 「不听完才是推理游戏，听完就是**汉语四级听力**… 真相是从'出题篇'推理出来的，把'解答篇'都听完了就没必要推理了。」

《暗潮》目前 100% 的谜题都建立在「可自由点开的邮件 / 照片 / 地方志 / 笔记」之上，
**这是本项目最大的单点风险**，详见 §5 第 13 条。

## 2. 与本作现状的逐条对标

> 「本作现状」列的判断来自 `Bunny_1` 分支在 `ce30a3e` 上的实测。

| 维度 | 已发售作品的做法 | 《暗潮》实测现状 | 差距 |
| --- | --- | --- | --- |
| **提示/求助** | 零计时提示、零自动催促。Obra Dinn 完全无提示仍为标杆。Golden Idol / Roottrees 为**主动索取 + 刻意加摩擦**，且**只给方向不给答案** | `data/task_guides.json` 12 条引导项中 `hint` 字段 **0 条**；二幕 T02–T07、三幕、四幕**无任何求助入口** | **大** |
| **设计化教学关** | Golden Idol 第 1 案、Unheard 第 1 章、Roottrees 三姐妹、Obra Dinn 四人序幕，均为专门设计的教学案例 | 第一幕 A–K 为线性流程，无独立教学关 | 中 |
| **阶段门槛** | 门槛是**具名的类型化断言**（填句子/填名字/回答具体问题），**绝不是收集百分比** | `confirmAct3Stage` 用全部线索 ID；`finishAct2TaleSorting` 要求 12 张卡全摆；`act2T01Controller` 要求两类指定词都搜过 | **大** |
| **可选内容标注** | Golden Idol 在**同一面板**标注「剩余谜题通常是可选的」；Roottrees 正确填入的**可选**项同样锁定并从候选池移除 | 无关键/可选区分；玩家无法判断哪些可跳过 | **大** |
| **热点可发现性** | Golden Idol 开局提供**「显示线索高亮 / 不显示」二选一**（GameLuster 明确记载，且攻略圈普遍推荐开启） | `photoViewport.css:24` 标签默认 `opacity:0;visibility:hidden`，仅 hover/focus 显示 | **大** |
| **坐标正确性** | 热点必须对应真实物件 | `object-fit:cover` + 容器百分比定位 → 容器比例≠4:3 时热点漂移到错误物体（见 `00-规划与实测发现.md` §2.1） | **高危 bug** |
| **可查阅性** | 线索板/笔记在**答题时也可打开**（Roottrees 明示 "including when filling in the family tree"） | 记事本独立应用，调查场景内无内联查阅 | 中 |
| **答题形态** | 填空句（Golden Idol）/ 输入名字（Roottrees）/ 具体具名问题（Unheard）。**多项选择才是「测验感」的来源** | 多为点击选择 + 排序题 | **大** |
| **错误反馈** | Heaven's Vault「接近时鼓励、偏离时**排除选项**」；Golden Idol「差 ≤2 项会提示」；Obra Dinn「线索不足」+**可强行继续** | 多为二值通过/不通过 | **大** |
| **失败代价** | 无命数、无计时、无 game over。Steam `Playable at Your Own Pace` | 无命数 ✅，但二幕 T01 有 **15 秒主动催促计时器** | 小 |
| **结局可达性** | Obra Dinn 范式：**永远能走到结局**，准确度解锁**额外**内容（第八章）而非作为通行税 | 四幕 T10 强制单点 | 中 |
| **机制复用** | 山河旅探因「一次性机制过多」被评为**谜题 1/10**、结论「想法太多但拎唔到重点」 | 四幕各用一套不同机制：照片曝光 / 民俗文献 / 镜头热点 / 密码+时间线 | **中高** |
| **排版** | XAG 101：正文行宽 **中文 ≤40 字**，可调字号至 ≥38px@1080p | 未见约束。**本作是纯中文阅读游戏，此条直接适用** | **大** |
| **触点尺寸** | WCAG 2.2 AA 为 24×24 CSS px；AAA 与 Apple HIG 为 44×44 | `.photo-viewport__marker` 48×48 ✅ | 达标 |

## 3. 品质评分卡（可逐条打勾验收）

> 用途：任何工单交付后，主审按此打分。**每条都必须能指出代码或实测位置**，不接受「已优化」这类描述。

### A. 引导与防卡关

- [ ] A1 存在**主动索取式**提示入口，且提示**分级**（当前问题 → 该对照哪些材料 → 具体动作），**第三级仅在玩家再次索取时出现**。
- [ ] A2 提示**永不给出答案**，只指向位置或关键词。
- [ ] A3 全局**无计时器**、**无自动催促**；不得因阅读时长判定卡关。
- [ ] A4 任何受阻操作都能就地得到**不含剧透**的原因，并附「查看相关材料」入口。
- [ ] A5 第一幕存在**设计化教学**，只教一个动词。

### B. 推理结构

- [ ] B1 每幕门槛是 **≤5 条具名类型化断言**（填空/命名/具名问题），不是数量计数。
- [ ] B2 每条断言在界面上标注 **关键 / 支线（可选）**，且二者同面板展示。
- [ ] B3 存在至少一条**必须经过变换才能读出**的决定性断言（照片曝光 / 民俗解码），使「全点一遍」无法直接得出答案。
- [ ] B4 线索板在**填写断言时仍可打开**。
- [ ] B5 等价选择顺序互换不应判错；只有真正时序题才要求顺序。
- [ ] B6 阅读顺序不受门槛限制：不得出现「先答对才能读材料」。

### C. 交互与空间

- [ ] C1 提供**「显示可交互物高亮」开关**（首次进入可选择），关闭后仍可完成。
- [ ] C2 缩放/平移到任意位置后，**返回与主要行动入口仍在视口内且可点击**。
- [ ] C3 热点坐标在**任意容器宽高比**下均对应正确物件（需有跨比例回归测试）。
- [ ] C4 动词不超过三个且视觉可区分：**查看**（不改变状态）/ **调查**（入线索板）/ **提交**（仅推理面板内）。
- [ ] C5 全流程可**纯键盘**完成，含照片平移缩放。

### D. 反馈与容错

- [ ] D1 错误提交给出**接近度分级**（如「差 ≤2 项」），而非纯通过/不通过。
- [ ] D2 反馈指向**未满足的约束**（「密码长度对，第 2 位对不上你已知的年份」），不指出正确项。
- [ ] D3 证据明显不足时可**软阻止**（含「仍要继续」选项），但不消耗进度。
- [ ] D4 连续正确累计**正向标记**，不做惩罚。
- [ ] D5 **无命数、无体力/电量资源**。

### E. 排版与无障碍

- [ ] E1 所有阅读面板（邮件 / 记事本 / 地方志 / 微信）正文行宽 **≤40 中文字符**。
- [ ] E2 字号可调，且 ≥38px@1080p 等效。
- [ ] E3 关键状态**不仅以颜色区分**。
- [ ] E4 照片曝光等核心机制提供**高对比**选项。
- [ ] E5 手存与自动存档**分槽**，自动存档不覆盖手存。

## 4. 明确**不要**做的事（有反面证据）

| 不要做 | 反面证据 |
| --- | --- |
| 命数 / 惩罚槽 | Ace Attorney 社区长期讨论「是否该退休惩罚系统」（r/AceAttorney） |
| 体力 / 电量资源 | 《橘猫侦探社》玩家反馈「电量系统确实让人别扭」 |
| 末期自由探索 + 隐形墙 | 《山河旅探》后期被批「令投入世界的程度大减」 |
| 叠加第 4 个行内动词 | 《Sherlock Holmes: The Awakened》的 pinning 系统被评测指为**既困惑又无谓** |
| 「拖延时间等你发现」式线索文本 | 《完美的一天》15–20h 中仅约 5h 是有效体验，其余为缺乏指引造成的重复 |
| 前一小时手把手 | Obra Dinn、Her Story 均**零提示**且被视为标杆；40 分钟的体量正是这个选择的红利 |

## 5. 本项目最高优先级的三条

1. **拆掉「数量型门槛」**（B1）。当前 `confirmAct3Stage` 的全线索要求、志异的 12 卡排序、
   T01 的双搜索 Flag，本质是把「做完清单」伪装成「完成推理」。这是与标杆差距最大、也最伤推理体验的一项。
2. **补齐主动索取式分级提示**（A1–A3）。三幕与四幕目前**零求助入口**，
   而中文同类作品《完美的一天》的教训是：引导不足比引导过度更致命。
3. **修掉坐标漂移**（C3）并加跨宽高比回归测试。这是正确性缺陷，且「点对东西」正是本作核心动词。

## 6. 证据缺口（如实标注，未编造）

1. 未找到任何一款已发售作品有**明确命名的「重置视角 / 居中」**控件的公开记载。
   最接近的可引用标准是 Steam `Camera Comfort` 标签文本。§2 未据此下强结论。
2. **44px 触点并非游戏行业标准**：来源为 WCAG 2.2 AAA 与 Apple HIG；
   WCAG 2.2 AA 的规范要求是 24×24 CSS px。对浏览器游戏，**WCAG 2.2 直接适用**。
3. 未找到任何一款本作研究范围内的已发售作品提供字面名为「reduced motion」的开关；
   行业实际用词是 `Camera Comfort`，2D 点击游戏通常靠「没有镜头晃动」默认获得该标签。
4. **Papers, Please** 的点阵错误提示来自 Reason.com 采访（二手来源），未在游戏内核实字面文本。
5. 《The Room》系列、《Disco Elysium》、《Road 96》未取得可靠可引证据，本次未纳入。
6. 除 XAG 101 的 40 字行宽外，未找到更多已发布的中文游戏排版规范。
