## 映射与构建

- 发布副本位于 `src/assets/compressed/`，按源目录和文件名镜像；[`asset-map.json`](../../src/assets/compressed/asset-map.json) 记录141个源相对路径到发布路径映射。原141张图片仍留在原目录受 Git 管理。
- `src/core/assetLoader.ts` 只对压缩目录建立资源 glob，按旧优先顺序解析登记文件；`AssetLoader` 公共接口、ID、`act4AssetPath()` 原语义以及未映射路径返回 `undefined` 的行为不变。
- [`asset-id-audit.json`](asset-id-audit.json) 按旧 loader 逐条审计 `data/images.json` 的138个带文件ID：138个均可解析到发布图、归并为134个唯一源路径，四组源文件各由两个ID复用，当前缺图为0。
- `src/data/spriteData.ts` 的6张 UI／头像图集改为引用压缩副本；裁切坐标及1254×1254、1536×1024尺寸未动。`src/imageAssets.css` 仅将桌面壁纸改为外置 WebP URL，并显式 `?no-inline`。

本分支唯一一次普通构建 `npm run build` 通过，TypeScript完成、Vite转换286 modules；`dist` 共145个文件、42,874,240字节，包含141个WebP、CSS、JS、HTML和原有占位 README。唯一一次离线构建 `npm run build:offline` 通过，Vite转换284 modules；离线 manifest列144个文件、42,889,973字节（40.90 MiB），另有manifest本身。离线包实际含141个WebP，未包含原PNG/JPEG。相较工单基线143文件、209,181,841字节，离线manifest体积下降约79.5%；壁纸现作为外置发布资源。

这些是提交前工作区构建；离线 manifest 写入当时的基线 SHA `697d98199b3f8ac63d4e591a13f89fe7a6f6145e`。`dist/` 和 `暗潮离线/` 均为可再生输出，不提交。集成提交后的发布包应由主审重建。
