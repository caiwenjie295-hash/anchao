## 目标与冻结原则

- 桥头和图书馆使用已接入的 `IMG_A2_T02_001`、`IMG_A2_T03_001` 作为宽屏全场景背景；前景面板为高对比的半透明磨砂质感。桥头玩家直接选照片中的老人，局部放大后看对话。图书馆先选目录，再点击照片中的书架查看局部特写及卷册，书页阅读区保留原有仿真排版和清晰度。
- 高中以场景照片为主交互面，调查点直接落在对应图像区域，保持可见提示与键盘可操作；地点导航保留但降为辅助。消防栓仍只是画面内容，不设热点、笔记或可疑提示。
- 关键阶段完成后提供主动的“进行下一步调查”入口，点击后才展示全屏黑幕；T01 搜索成功不再自动切桥头。原有阶段、Flag、笔记、资源 ID 与第一二幕结论不变，schema 保持 6。
- 第二幕小月聊天补主角回复，全部登记在 `data/chats.json`；微信会话提供明显的向上查看旧消息与回到最新消息操作，不强制打断玩家的历史阅读。
- 全局待办默认收起；暗示型步骤可以单独点开查看较具体的提示，答案只在玩家主动点开后出现。T05 双 S 比对后待办持续引导玩家打开浏览器核查启明，不出现空档。
- 修复浏览器查询框清空后回填旧词的问题；用户能用 Backspace 删到空并输入新词。
- PC 宽屏全屏优先；按用户要求本轮不进行窄屏精修。

## 验收

- 桥头四名老人可从照片上用可见热点选择；焦点人物有照片局部放大；对话、出示证据、辨字和原有状态链仍可完成。
- 图书馆背景图全屏可见，书架照片可直接点击并看局部；类别线索有视觉提示但不直接揭晓目标卷册；书页、关键词、摘录保持原有可读效果。
- 高中门、走廊、教室、光荣榜、办公室等照片承担地点和线索入口；主要调查不依赖图片外的卡片按钮。
- 转场在玩家主动点击入口前不遮断调查；继续进入后可正常确认黑幕、重载、清零；旧存档兼容。
- 微信历史记录能明显地向上浏览并回到底部，小月与主角有自然往来。
- 待办默认收起，主动点开暗示才显示答案；完成双 S 后明确指向浏览器。
- 浏览器搜索词可以逐字删至空，不会回填。
- `git diff --check`、`npm test`、`npm run build`、`npm run build:offline`、`npm run test:offline` 均通过；PC 宽屏真实浏览器检查桥头、图书馆、学校、微信、待办、浏览器和转场。
