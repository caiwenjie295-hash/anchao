## 目标与权威资料

完成第二幕 T05。玩家读完 T04 的“**小A缺什么？**”后，通过小月微信回到高中，调查小A休学及返校变化、王澳成绩和启明名称，在学霸笔记发现双 S，与第一幕山洞符号进行并排、放大和半透明重合比对。终点只建立“鸡公岭 ↔ 小A / 启明”的关联。

执行前完整阅读 `AGENTS.md`、`维护导航.md`、`docs/协作开发与Git工作流.md`、`docs/第二幕_T01-T04_交接文档.md`、本工单、`game/04_暗潮_可追溯开发规范.md` 和 `game/05_暗潮_第二幕_开发步骤规范_T01-T07 (1).md` 的 T05。小说及 `game/**` 只读。规范里的旧称“鸡头岭”在玩家可见文本中统一为项目运行名“鸡公岭”。

## 必须交付与叙事边界

1. T04 确认归纳后出现小月的新微信内容：三人旧照、初高中照片、普通玩笑、聚会照、小A旧照及小月日常。至少一半内容只是生活信息；照片均可打开查看，缺正式美术时使用明确标注的本地资源空位和说明，不用远程图片，不把每张照片转成 Flag。
2. 微信内有明确但中性的“回高中看看”动作。玩家主动触发后才进入 T05；重载或从学校返回桌面后可继续。桌面任务引导先指向微信，再指向学校调查，不给出推理结论。
3. 学校有校门、走廊、小A旧教室、小月旧教室、厕所方向、消防栓、光荣榜、老师办公室和宣传栏。移动路线与可访问名称清楚，场景可返回桌面。小月或老师可自然提示“以前展示过他的笔记”，避免忽略学霸笔记后卡关。
4. 老师完整说明：小A高二休学两个月；返校后安静、与同学疏远、几乎只学习，成绩迅速提升。不得让老师提前给出原因或 T06/T07 结论。
5. 光荣榜以版面构图、层级和可读文字引导查看王澳，不做小点击区或像素级找物。名次必须按 `600 → 400 → 300 → 130 → 88 → 53 → 20` 完整呈现；感谢文字必须出现“启明青少年成长中心两个月来对我的教育和培养”。
6. 学霸笔记页边出现双 S。比对界面必须提供并排、双方放大、半透明重合三种实用操作；重合层可调透明度并可对齐。第一幕山洞符号使用现有 `IMG_A1_H_003` 与同一符号绘制源，避免画出两个不同图案。确认比对之后才写入关联笔记。
7. 消防栓只作第三幕伏笔：自然出现在走廊/厕所方向，不标红、不加可疑文案、不写笔记、不放进任务引导、不参与任何 T05 解锁或谜题。`FLAG_A2_FIRE_HYDRANT_SEEN` 只记录经过该画面，不驱动当前反馈。
8. 不实现启明网页调查、旧论坛、诊断、来源真相或 T06/T07 的任何推论。不得声称小A“缺什么”或解释双 S 的真实含义。

| 学校写入方法 | `visitAct2SchoolArea(areaId: string): void`、`inspectAct2SchoolHotspot(hotspotId: string): void`、`acknowledgeAct2TeacherAccount(): void`、`readAct2SchoolRanks(): void`、`readAct2QimingTestimonial(): void`、`inspectAct2SchoolNotebook(): void`、`confirmAct2SchoolSymbolMatch(): void`。所有方法只在 `school` 阶段及对应前置成立时生效；非法/未知/重复 ID 无副作用；Flag、笔记和事件由 StateManager 写入。 |
| 进入与恢复 | `A2_T05/school` 从 `src/App.tsx` 经 `Act2Experience` 显示；返回桌面只改变瞬时显示，重载从校门/学校总览恢复，已取得的证据与笔记不丢失。清零回到第一幕默认状态。 |
| 比对确认 | 必须先有 `FLAG_A1_SS_FOUND` 与 `FLAG_A2_SCHOOL_SS_FOUND`，玩家实际打开比对并使用重合视图后才提供确认操作；未满足前置不能设置匹配 Flag。并排、缩放、透明度与对齐参数仅组件瞬时状态，重载后可重新操作。 |
| 事件 | 新增 `act2:school-entered`、`act2:school-area-visited`、`act2:school-hotspot-inspected`、`act2:school-symbol-matched`；`progress:reset` / `save:completed` 的 schemaVersion 为 `4`。 |

### Flag 与笔记

以下七个 Flag 原样登记在 `data/flags.json`，全部为布尔、默认 false：

| Flag | 唯一触发 | 当前用途 |
| --- | --- | --- |
| `FLAG_A2_SCHOOL_ENTERED` | 微信入口调用 `enterAct2School` | T05 阶段开始 |
| `FLAG_A2_FIRE_HYDRANT_SEEN` | 走廊/厕所方向自然呈现消防栓时 | 仅留第三幕视觉记忆，不用于引导或解锁 |
| `FLAG_A2_LEAVE_OF_ABSENCE_KNOWN` | 完整听取老师说明 | 记录休学与变化 |
| `FLAG_A2_SCORE_CHANGE_KNOWN` | 查看七段王澳名次 | 记录成绩变化 |
| `FLAG_A2_QIMING_NAME_FOUND` | 阅读感谢文字 | 记录启明名称 |
| `FLAG_A2_SCHOOL_SS_FOUND` | 查看学霸笔记页边符号 | 开启比对 |
| `FLAG_A2_SS_MATCH_CONFIRMED` | 玩家完成双 S 比对并确认 | T05 收束 |

笔记通过 `StateManager.addNotepadAutoEntry` 幂等写入，内容登记在 `data/notes.json`：`NOTE_A2_T05_001` 老师证言、`NOTE_A2_T05_002` 王澳名次、`NOTE_A2_T05_003` 启明感谢文字、`NOTE_A2_T05_004` 双 S 关联。前三条分别在对应 Flag 产生时加入；第四条仅在匹配确认时加入，其结论限于“鸡公岭 ↔ 小A / 启明”。消防栓没有笔记 ID。
