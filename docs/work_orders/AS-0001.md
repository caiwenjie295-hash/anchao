# AS-0001 第二幕用户图片接入

> 状态：权威执行工单
> 基线：`c16e854`（`main`）
> 唯一写入者：Codex
> 分支：`codex/AS-0001-act2-art`

## 目标

将用户放在主工作区 `src/第二幕/` 的 12 张图片与 Codex 生成的小A、小月高中双人合照接入第二幕 T02、T03、T05 正式游戏及离线入口。

## 冻结接口

- 不改资源 ID、Flag、阶段、存档 schema 或状态方法。
- 接入 `IMG_A2_T02_001`、`IMG_A2_T03_001`、`IMG_A2_T05_001–011` 共 13 个资源。
- 图片以本地文件编入构建；场景和微信通过 `assetLoader` 按 ID 读取，缺图时保留现有占位。
- 用户原始 PNG 保留在主工作区且不移动；任务分支收录适合单文件离线构建的 JPEG 副本。双人合照由 imagegen 以小A、小月及公告栏照片为参照生成。

## 验收标准

- 13 张图片在对应的桥头、图书馆、学校场景及微信照片中可见；微信照片可在现有查看器放大。
- 光荣榜成绩仍由 HTML 准确呈现；学霸笔记双 S 仍由共用图形叠加；消防栓不被突出。
- 高中旧照仅有小A与小月两人，背景与学校公告栏一致。
- 离线构建无外部图片请求；PC 宽屏全屏检查无遮挡或不可读问题。
