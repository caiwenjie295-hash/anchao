# A3-T05 搬空的广播室

> 状态：待 A3-T04 验收后冻结；唯一功能写入者为领取本单的外部执行 Agent
>
> 建议分支：`agent/A3-T05-ruins-broadcast`，从届时稳定 `main` 建独立 worktree；执行者不得合并

## 目标与边界

玩家在设备几乎搬空的广播室找到另一张标题为 `13aCK` 的纸片，正文是“老鼠、血、草垛、木房子、玫瑰、表”。与 T04 的 `VVaKe` 并列保存为两组不明词表；玩家可以怀疑广播曾被用来进行改造，但本幕不播放可操作的指令广播、不解码，也不把设备缺失误描写为仍在运转。

## 交互与状态

- 沿地下走廊进入广播室，先检查空设备位、电线和旧桌，改变低视角后发现纸片。主动拾取写 `FLAG_A3_13ACK_PAPER_FOUND`；可与 `VVaKe` 并排查看并标注“两张词表”，不可自动得出 wake/back。
- 退出时空气里的陈油和酸臭由文本/音效承接，引向深处厨房；视觉不要在广播室凭空展示厨房证据。
