# T06 实施计划

1. 从广播室继续向里，走廊油腻酸臭。门牌“厨房重地，闲人勿入”由准确文本叠层出现。进入时先看整体，不立即把空神龛单独突出。
2. 玩家左右查看生锈大锅、锅内残渣、砍骨刀、地面大骨和上方旧铁钩。镜头移动要像举手机扫视同一间厨房；骨头只有来源不明的普通大骨形状。
3. 小月根据既有证据提出“难吃的配餐与奖励的鲜肉”猜测，主角保留疑问。玩家靠近最深处木神龛，发现只有底座；小月突然要离开。
4. 回到较亮的一层后，两人把刚才神龛照片与鸡公岭破庙的黑补母塑像及空座并排看。玩家主动确认供奉关联，文案保留物件具体如何移动的不确定性，进入 T07 的返程。

**视角链：**厨房门 → 整室广角 → 大锅/刀 → 地面骨头 → 抬头铁钩 → 尽头神龛 → 空底座近景。比较界面使用已有破庙图与本 T 第 7 图，不再生成“拼贴结论图”。

**提示与限制：**小月提醒“先上去再说”是情绪转折，不是强制玩家漏查已开放物件；离开后可在证据层复看。不要写“人体骨骼”等超出原文调查者认知的鉴定语言。
