# 第三幕视觉与交互总规范

## 统一画面语法

- **摄影手法：**低饱和、极度写实、普通手机后置广角拍摄。约 24–28 mm 等效焦距，4:3 横构图为默认，主人公成人站姿镜头约 1.6 m，蹲姿约 0.8 m。允许真实的边缘畸变、暗部噪点、轻微失焦、雨后污迹；禁止电影镜头光晕、青橙调色、过度 HDR、夸张广角或绘画质感。
- **时间与光线：**阴天、秋冬、下午逐渐转暗。外门和操场靠自然漫射光，教学楼是窗外冷灰自然光加小手电，地下室只靠手电照亮局部。回程比进入时稍暗，但不能突然从白天跳成深夜。
- **场景年代：**启明已废弃多年，红砖墙、黄底红字金属牌、锈铁门、爬山虎、刀片铁丝网、教室旧课桌、剥落标语、老式设备。保持普通真实建筑的尺度和维修痕迹，避免夸张的“恐怖屋”道具。
- **第一人称：**主角不露脸，不使用悬浮无人机视角。只有开门、拨叶、举纸、蹲下等动作可出现少量手或鞋。小月主要以同一件深灰防水外套和卡其色登山鞋的背影/局部入画，不频繁给正脸；每张图都保持她站位与动作逻辑。
- **连续性锚点：**外门右侧水泥柱有被藤蔓覆盖的标牌；外门内是第二层刀片铁丝围栏、操场、主楼配电箱。主楼一层长走廊的教室在左，靠厕所的拐角窗下有消防栓，转弯进入禁闭区，尽头向下的楼梯通往地下走廊；地下依次经过档案室、广播室，厨房在更深处。每组画面靠同一个门框、裂缝、污渍和光源维持方向。
- **文字控制：**“启明青少年成长中心”、24/48/72、`VVaKe`、`13aCK`、纸片上的词语及标语优先由程序文字层覆盖或单独排版，图片描述只给文字的物理位置和留白。生成模型不负责输出准确汉字或字母。双 S 可后期以既有矢量/叠层加入，并保持旧关卡形态一致。
- **限制：**无血腥猎奇、无明确人体残骸、无怪物、无祭祀显灵、无超自然特效。厨房骨头只是一段来源未明的大骨，第三幕不将猜测拍成已证实事实。

## 单张图片的通用生成前缀

> 低饱和、极度写实的手机实拍照片，4:3 横幅，普通手机后置广角约 26 mm 等效视角，第一人称成人眼高，阴雨后秋冬山区的自然灰光，真实旧建筑材质与使用痕迹，轻微手机噪点和自然曝光，构图不刻意对称，不做电影调色，不做绘画或游戏概念图，无超自然效果，无可读的大段生成文字。保持与上一张获批参考图完全相同的建筑结构、门窗位置、污渍和镜头朝向。以下描述为本张新增的具体视角与物件：

## 图片与交互的关系

| 动作 | 镜头处理 | 交互边界 |
| --- | --- | --- |
| 看向 | 切换到同一站位不同朝向的照片，使用共同门框/墙面定向 | 提供可见热点与键盘列表，不做盲点式像素找物 |
| 靠近 | 切到同物件中近景，位置和形状不变 | 可按返回键退回前一站位；不传送到陌生角度 |
| 蹲下 | 相机高度降低，消防栓侧背面才进入视野 | 由小月的记忆与地点线索提示，不随机试每面墙 |
| 手电 | 同张图以程序遮罩/光斑局部揭示；必要时生成一张有光照片 | 不设计有限电量、强制倒计时或必须精准照中 1 像素 |
| 拍照/收集 | 留下稳定资源 ID 与记录；物证可在图层中放大 | 旧照片和新物证并排比对，结论须玩家主动确认 |

本次只产出文字计划和图片描述；不生成图片，不向 `data/images.json` 登记虚假的已存在文件。后续美术任务按 `src/第三幕/IMG_A3_TXX_YYY.jpg` 命名，接入时扩展资源加载与离线内联，并逐张检查手机视角连续性。
