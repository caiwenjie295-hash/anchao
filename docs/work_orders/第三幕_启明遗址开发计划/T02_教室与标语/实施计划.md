# T02 实施计划

1. 从 T01 主楼门跨入一层长走廊：云层过滤后的惨白天光从侧窗进来，地面有玻璃与旧课桌碎片；手电可扫视但不限制电量。
2. 走近左侧教室，切入门口广角，再到讲台前。由玩家看向黑板才显现大量歪斜双 S；再看墙上“改变从服从开始”等标语和黑板上方两只喇叭。
3. 让玩家调出此前宣传资料做一个轻量对照：公开说辞与这里的纪律/服从空间不一致。记事本记“现场有与论坛描述相合之处”，不把论坛每项叙述全认定为事实。
4. 回到走廊，前方拐角窗下消防栓自然经过；小月可听见不明来源的脚步回声，二人停下后发现并无可确认的人。向右转进入 T03。

**视角链：**主楼内走廊 → 左侧教室门 → 教室全景 → 黑板近景 → 标语/喇叭仰视 → 返回走廊拐角。第 6 图应保留消防栓，但不采用近景或交互标记。

**提示与限制：**玩家可以先检查任一物件，三处主要线索看完再确认阶段结论。手电是阅读工具，不是找准确像素的游戏。绝不让消防栓在本 T 显示“可疑”文案。
