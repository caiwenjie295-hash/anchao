# T03 实施计划

1. 从 T02 拐角进入无窗区域，手机画面自然曝光变暗，小月仍同行。玩家远看密集窄门，再走近第一扇。
2. 先读 24 小时标记，检查三孔和仅能从外面打开的挡板；回望另一侧门，才发现标记依次是 48、72 小时。
3. 记事本记录“现场有禁闭室，旧论坛部分陈述有对应”，但不把黄山/月子的所有经历视为证实。
4. 走廊尽头是向下楼梯。玩家用手电观察黑暗，小月表达害怕仍愿继续，玩家确认后下楼。拳头大小的老鼠影可掠过光斑，但不做硬性跳吓或怪物追逐。

**视角链：**禁闭区入口 → 24 小时门近景 → 从门外看孔/挡板 → 48/72 门渐进走廊 → 楼梯口 → 楼梯半程向下。楼梯半程终点衔接 T04 地下走廊。

**提示与限制：**需要时小月提示“这些数字像时间”；不能用灌输式旁白直接说出机构怎样惩罚学生。玩家下楼前可原路返回补查。
