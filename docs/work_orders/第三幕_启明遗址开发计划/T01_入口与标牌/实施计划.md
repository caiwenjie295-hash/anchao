# T01 实施计划

1. 从第二幕终幕自然接到旧址外门。第一张图展示锈铁门、右柱爬山虎与围墙，玩家可左右看，不用新地图或桌面窗口。
2. 玩家走近右柱拨开爬山虎；同机位前后两张图只改变枝叶遮挡，程序叠加准确的“启明青少年成长中心”字样。可调出 T07 的旧合影并主动确认大门是同一处。
3. 小月先从锈门缝挤入，主角收好衣服后跟入；不把动作做成多次失败的 QTE。转头后见第二层刀片铁丝网，走有门的入口而非攀爬。
4. 穿过旧操场，检查主楼门口的剪断配电箱，形成早前山路电缆的弱回声；不要求玩家必须做过本幕外的电缆玩法。主楼门可进入 T02。

**视角链：**外门远景 → 右柱近景 → 同机位清理后 → 门缝内视角 → 第二层围栏 → 操场与主楼。返回时沿链倒走，保留已清理标牌的状态。

**失败与提示：**未发现标牌时，小月自然提醒“这根柱子被藤挡住了”；未比对时可反复查看合影；不要求点中薄藤蔓单个像素。检查配电箱可选，不阻止进入主楼。

**验收重点：**两道围栏的前后关系、右柱位置、宣传照与现场是同一大门的可比性；图像缺席时流程仍完整。
