# A3-T01 旧址入口与双层围栏

## 目标与边界

玩家接续 T00 末镜头，从同一扇启明旧址外门前开始，以第一人称拨开右侧门柱爬山虎，对照旧宣传合影确认“启明青少年成长中心”标牌，再经锈门与第二层刀片铁丝围栏进入操场，发现剪断的配电箱线路。本 T 结束在主楼入口。山路电缆/排水沟追踪已在 T00 完成，不能回改第二幕。

## 交互与状态

- `FLAG_A3_GATE_REACHED` 为唯一入口前置，且由 T00 写入；进入后复用 T00 的图片视角调查壳，按本 T 需要扩展拨叶、旧照比对与围栏通行，鼠标/键盘/触摸均能走完整路线。
- 清理遮挡后，玩家主动把标牌与 T07 旧宣传合影对照，才写 `FLAG_A3_QIMING_SITE_CONFIRMED`；不能靠点击场景入口自动授予。穿过第二层围栏后写 `FLAG_A3_INNER_FENCE_PASSED`，完成后进入 `A3_T02`。
- 标牌位置、双层围栏、操场/配电箱的空间关系以本文件夹图片清单冻结。不得让小月分头行动、把她锁在门外或提供不合逻辑的翻墙小游戏。
