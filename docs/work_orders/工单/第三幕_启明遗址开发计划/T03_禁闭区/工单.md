## 目标与边界

玩家转过教室尽头后看到无窗的小房间，逐步确认门上“24 / 48 / 72 小时禁闭室”标记、三个窥孔及外侧活动挡板。现场支持旧论坛的禁闭描述，但玩家不应由此自动认定论坛发帖人身份。尽头发现向下的楼梯，小月与主角共同决定继续。

## 交互与状态

- 复用第一人称图像壳，通过同一走廊的近远视角展示几间不同禁闭室；检查三个时长与门结构后登记 `FLAG_A3_CONFINEMENT_SITE_CONFIRMED`。
- 玩家可以后退回教室区，不会误触“进入地下室”不可逆转场。地下楼梯用手电照亮后由玩家确认下楼，进入 `A3_T04`。远处脚步和老鼠只制造不确定感，不出现可证实的怪物或战斗。

## 验收与提交

- [ ] 24/48/72 是三间门或一条渐进走廊，不在一扇门上随意改数字；窥孔/挡板方向与门外观察一致。
- [ ] 玩家主动确认禁闭现场后才有阶段 Flag；楼梯可返回，重载不会再次播惊吓或跳过门槛。
- [ ] 无真实图片时也能完成，暗光下焦点/热点可见，键盘/触摸均可用；不设突然死亡或倒计时。
