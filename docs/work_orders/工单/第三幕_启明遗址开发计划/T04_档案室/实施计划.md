# T04 实施计划

1. 从 T03 楼梯踏入狭长地下走廊，手电先扫到档案室门牌。画面暗但可辨墙线和另一端的广播室方向。
2. 推门见几排旧金属架，年份字母标签（如“2014 年 D”“2015 年 F”）仍在，资料大多已空。玩家查看书架后没有立即得到解释，保留“被搬走了什么”的疑问。
3. 下移手机/手电角度，角落灰尘和破纸边露出。玩家蹲下拾起一张折旧纸片；展开后通过 UI 读到 `VVaKe` 与六个词，拍照或收入证据袋。
4. 玩家退出回到同一条地下走廊，下一扇广播室可见；不在此时强制解释词语或播放真实广播。

**视角链：**地下走廊门牌 → 档案室门口 → 空架/年份标签 → 地面角落 → 纸片近景 → 回看走廊广播室方向。书架与门框方向不可颠倒。

**弱提示：**看完架子若没发现纸片，小月说“地上好像还有一小张”，同时扩大地面可点区域；不闪烁高亮或要求精确点击纸角。
