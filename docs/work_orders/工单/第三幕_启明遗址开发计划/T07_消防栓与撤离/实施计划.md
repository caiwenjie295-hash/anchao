# T07 实施计划

1. 小月拉主角从地下回到一层，阴天自然光比地下手电更让人安心；二人边走边试图缓和情绪，不另造恐怖事件。
2. 走过教室与厕所方向时，小月停下，想起小 A 高中时常在窗前蹲着系鞋带。玩家站姿只能看见一个普通老消防栓，既呼应 T02 的背景，也不直接显露秘密。
3. 玩家点击“蹲下看看”后镜头降到膝部高度，消防栓侧后方的空隙才进入视野。伸手取出塑料袋/透明胶包裹的褐色笔记；拆开见 `A.W` 与小 A 的字迹。小月催促天黑前离开，详细阅读留到安全处。
4. 玩家原路出主楼、穿操场与围栏，镜头接回 T01 的旧址入口但光线稍暗。第三幕以“小 A 真的来过这里，留下东西给我们”收束，不给出是否走出去的答案。

**视角链：**上楼见自然光 → 教室/厕所拐角 → 站姿消防栓 → 小月蹲姿提示 → 玩家蹲下看侧背面 → 取出包裹 → 笔记扉页 → 离开主楼的晚光。出口可以复用 T01 外门母图并制作光线变体，无需再生一张布局不同的门。

**弱提示：**若未蹲下，先给小月一段关于系鞋带与窗户的具体回忆，再提供明确的视角改变按钮；不靠闪光箭头标出消防栓背后。
