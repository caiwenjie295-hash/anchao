# T00 实施计划

1. **约定后的旅程。**第二幕 T07 的终幕之后，用短镜头表现两天后出发、约十小时车程和县城补给。核桃、卡其色登山鞋作为人物小细节即可，不做购物操作。傍晚入住后，清晨从山脚进入熟悉的鸡公岭。这里是人物连续行动，不插独立桌面章节界面。
2. **旧电缆引起误判。**阴云压着山路，小月查看离线地图。她被雨水冲出的旧电缆绊到，玩家看近景确认是人造线而非藤蔓；两人沿线前行，发现线在泥坡处断掉，只能折回原路。电缆不直接指向启明门口。
3. **雨洞与石庙。**雨变大，回到第一幕出现过的洞穴避雨；小月谈起小 A 在高中时的习惯，主角给她看先前拍到的石庙照片，补母传说与底座细节重新进入讨论。雨停后再到石庙核对位置，只留下“两尊”的怀疑，随后沿原路准备下山。
4. **从水流找到人工路线。**小月指出一片坡面上水流分叉太整齐。玩家可切换“正常水痕/异常分流”视角，靠近检查湿泥下笔直的混凝土排水沟；再沿沟向上看见红砖、等距树木与旧路痕迹。以这些可见证据确认向上追踪，避免无根据的随机转向。
5. **外墙交给 T01。**沿旧路见残缺口号、红砖围墙，最后停在锈门和右侧被藤遮住的柱子外。T00 只确认找到了废弃建筑，不揭牌、不比旧宣传合影、不穿外门。下一次推进使用同一站位进入 T01。

**视角链：**车内 → 县城补给 → 山脚 → 电缆远景 → 电缆近景 → 雨洞 → 洞内谈话 → 石庙重访 → 坡面水痕 → 排水沟近景 → 红砖旧路 → 外墙锈门。旅途前两镜允许简短时间跳切；从山脚到外门坚持空间与天气连续。洞穴和石庙可直接引用第一幕原图/裁切，新槽位仅用于同地不同时间的补充角度。

**图片缺席策略：**每个镜头先显示本地占位、场景方向和热点文本；找水流的操作由明确的“看向坡面”“靠近泥下硬边”选项完成。正式照片接入后，交互顺序、ID 和存档状态不变。

**验收重点：**第二幕 T07 末尾到旅途起点的时间解释；电缆断点不是错误终局；石庙与第一幕一致；排水沟的“往上走”有充分视觉证据；T00 末镜头与 T01 首镜头正反可对位。
