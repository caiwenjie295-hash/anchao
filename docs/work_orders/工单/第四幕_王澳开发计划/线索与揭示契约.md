## 固定顺序与玩家权限

```text
第三幕带出笔记
  → A4-T01 九页笔记与账号提示
  → A4-T02 旧邮件日期、两账号登录
  → A4-T03 微博清醒时间线
  → A4-T04 启明邮件与第三幕两纸比对
  → A4-T05—T07 2014 小 A 亲历重构
  → A4-T08—T09 2020 小 A 返校与最后几步
  → A4-T10 当下求证、三杯、数月后邮件
```

- 玩家可回看已解锁的笔记、邮件、微博和场景，但重看不重复写入 Flag/笔记。
- 小 A 第一人称段为叙事层，不是现实主角新获得的监控录像。现实调查笔记只能引用现实中可得到的纸张、账号、现场与公开资料；推论保留“可能”“与……一致”等证据等级。
- 密码、对照和日期是可操作的推理；2014 年被送走与 2020 年最后倒下是既定往事。不要设计看似能救出小 A、实际无效的伪分支或失败重试。
- 如果后续改编希望让主角获得 2014/2020 的确证材料，必须先由用户决定新增何种原文外物证，并独立修订事实层级；执行 Agent 不得自行补设录像、完整档案或目击证人。
