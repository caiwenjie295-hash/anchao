## 冻结产品规则

### T03 必修

- 所有玩家可见的翻页文案统一为“上一页 / 下一页 / 第 N 页”，不得再出现“叶”。测试名称、注释和可访问名称也同步改正。
- 修复完成结论卡与底部“返回桌面”在 1440×900、1024×768、768×1024、390×844 下的重叠及点击区域冲突。结果区必须按真实内容高度参与布局，禁止用 `z-index`、隐藏或固定高度掩盖。
- 从存档重载时，若正确目录已经访问并显示卷册，目录选中态和说明必须恢复一致；不能同时显示卷册又提示“请选择门类”。
- 维持目录→卷册→逐页→至少三个核心词→主动摘录的门槛，不允许页码直达目标页。

### T04 信息层级

- T03 摘录完成后才出现中性主按钮“继续查阅三篇志异”，显式进入 `A2_T04/tales`；不得自动跳转。
- 初始索引应有至少 5 条普通地方杂记作为噪音，三篇核心志异穿插其中。噪音只能提供时代/页码/一句普通摘要，不产生 Flag 或笔记。
- 三篇核心条目必须有可感知但克制的视觉暗示：沿用旧纸、墨色、褪色朱砂书签/馆员铅笔批注的方向；不得使用红色大框、闪烁、答案文字或三个同款发光卡片。
- 阅读面以原文为视觉主角：约 68–76ch 行宽、舒适行高、清楚段落节奏；现代文说明默认收起或次级显示，标题明确为“现代文说明”。
- 每篇读完后出现“加入调查笔记”，写入对应桌面记事本条目；重复点击幂等。场景内同时有三格“已收集材料”状态，返回桌面后可在既有记事本复核，不新增虚假桌面 App。
- 三篇都读完并已加入笔记后开放资料整理：四列固定为“人物 / 缺失 / 进食 / 获得与异变”，共 12 张卡片。支持拖放，也必须提供键盘/点击选择列的等价操作；错误放置不提交，多次错误后只锁定一个明显条目。
- 全部整理完成后缓慢出现两句原规范反馈，不显示“解谜成功”；玩家确认归纳后写最终 Flag 和一条问题笔记“**小A缺什么？**”，不得告诉玩家小A吃过什么，不进入 T05。
- 场景可返回桌面并从当前阅读/整理进度继续；重载保存，清零干净回到第一幕。

### 视觉方向

- 方向：老县志阅览桌上的“档案摊开”，不是后台仪表盘、通用卡片墙或营销页面。
- 色彩：保留 T03 深褐/旧纸/墨黑体系，朱砂只做关键条目标记和选中状态；成功/错误色只表达语义。
- 签名动作：点击核心目录条目时，褪色书签沿页边展开，阅读纸张以轻微位移和透明度进入；`prefers-reduced-motion` 下立即切换。
- 桌面与移动端都只保留一个主要操作。390px 不横向溢出，正文、辅助说明、收集栏、整理区和返回按钮必须自然纵向排列；主要触控目标至少 44px。
