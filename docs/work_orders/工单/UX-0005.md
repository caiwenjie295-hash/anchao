## 目标

使第四幕与第三幕采用同一套照片内探索语言。T01、T05–T10 中的线索、方向和推进动作尽量出现在照片对应的物件与边缘，支持点击、放大、拖动、触控及键盘。T02–T04 是互联网和软件调查，按真实邮件、社交网页的阅读和操作习惯组织谜题。整体探索层低饱和、半透明磨砂玻璃；证据原文、强线索对照和必要的清楚提示才用不透明阅读层。镜头与视角切换用轻微平移/放大和短暂黑色淡入淡出表示连续性。

## 实地探索 T01、T05–T10

- T01：笔记放在酒店桌面的照片中；从笔记热点打开可翻页阅读层。阅读层保留九页逐页登记、返回和顺序推理；路线判断与后续入口从桌上笔记、照片和离开房间的视觉区域发起。笔记原文须清楚可读。
- T05：七张生日回忆按原顺序，热点与空间目标对应：日记、教室、河边、家门、来人等。重要对话以局部阅读层呈现。每次推进来自画面内方向/物件，原有门禁和回看功能保持。
- T06–T10：每张图的主操作都由画面内热点或方向触发；各阶段谜题显示为紧凑的局部证据层，关闭后返回原视角。需要比较的纸片/记录可使用清晰不透明层。不能把阶段列表、通用“继续经历”按钮或大块“接下来”卡片作为默认主交互。画面仍要有可见的上下文、当前目标和回看入口，但尽量轻量。
- 按固定 `IMG_A4_Txx_nnn` ID 为所有 40 张图定义独立归一化热点坐标表。热点目标对应真实可见的物件或视线方向；抽象记忆/声音放在边缘低调标记，不伪装成实体。位置表与谜题状态分离。
- 复用 UX-0004 `PhotoViewport` 的平移、缩放、触控、键盘和过渡能力；如第四幕需要新增通用 props，先向主审报告并保持组件与剧情状态解耦。动画不能自动触发登记或跳过门禁；遵守减少动态效果设置。
