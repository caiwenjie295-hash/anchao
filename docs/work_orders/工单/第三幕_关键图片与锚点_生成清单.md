## 所有图片共用的生成前缀

将此段放在每张图片具体描述之前，并上传表格所列的参考图：

> 低饱和、极度写实的普通手机后置广角实拍，约 26 mm 等效视角，4:3 横构图，目标 1600×1200 像素。第一人称成人站姿相机约 1.6 m，蹲姿约 0.8 m；主角不露脸，只在实际伸手、拨叶、拿纸时允许少量手部入画。阴天或雨后自然灰光；地下仅有真实手电局部照明。保留自然曝光、轻微手机噪点、旧建筑的普通维修痕迹，构图不刻意对称。小月若入画，始终穿深灰防水外套、卡其色登山鞋，主要为背影或局部。与已批准相邻图保持相同门窗、裂痕、污渍、物件位置和朝向。不要电影调色、夸张 HDR、恐怖屋道具、怪物、超自然光效、鲜血或可辨人体残骸。所有需要精确阅读的汉字、数字、双 S、`VVaKe`、`13aCK`、`A.W` 留物理空位，由游戏文字层后期覆盖；不要让模型生成可读文字。

**交付规则：**每张只输出一幅无 UI、无边框、无水印的场景图，文件名使用表中的 ID 加 `.jpg`。先确认上一张母图再做同地点下一张。保持 4:3 横幅；不把多镜头拼成一张。文字、热点、手电交互和证据结论由游戏负责。

## 接入与验收提醒

1. 保存正式文件到 `src/第三幕/IMG_A3_TXX_YYY.jpg`；先检查每组母图与派生图的门窗、裂痕、镜头高度和方位，再批量接线。
2. **单纯把 JPG 放进目录不会自动显示。**目前 `src/core/assetLoader.ts` 只加载第一幕 `Photo_src` 和第二幕目录；接入时需增加第三幕资源映射，并在 `data/images.json` 对批准的 ID 写 `file`。不要给未完成图片虚填路径。
3. 图片不承载唯一线索入口：核对有图和缺图时热点、键盘、触摸、存档及离线流程一致。精确文字继续由网页文字层负责。
4. 分批运行 `npm test`、`npm run build`、`npm run build:offline`、`npm run test:offline` 和浏览器宽屏走查；确认外置图片未回退成 Base64 巨型 HTML。按当前用户安排，窄屏统一留待后续适配。
