## 冻结集成行为

### 1. 控制器生命周期

- `App` 必须创建且只启动一个 `Act2T01Controller`，与第一幕控制器放在同一个生命周期中，并在卸载时 `dispose()`。
- T01 只复用现有浏览器与桌面任务卡，不增加新的搜索 UI。
- 第一幕未完成、第二幕未启动或第二幕已离开 `search` 时，T01 控制器不得推进状态。

### 2. 场景壳与桌面往返

- 新建 `Act2Experience.tsx`，只负责根据 `act2Research.stage` 连接 `BridgeInvestigation` 与 `LibraryResearch`，不得硬编码其剧情正文。
- `search` 阶段保持普通桌面；`bridge` 和 `library` 阶段默认打开对应全屏场景。
- 两个场景的“返回桌面”必须真正关闭场景、恢复桌面可见与可聚焦；桌面上必须出现中性、可访问的“继续桥头调查”或“继续地方志调查”入口，允许恢复当前场景。
- 场景关闭只是瞬时显示状态，不改变剧情阶段、Flag 或已完成交互。阶段从 `bridge` 前进到 `library` 时，新的图书馆场景必须自动打开。
- 清零到第一幕后，任何旧的“已返回桌面”瞬时状态不得污染下一次游玩。
- 场景打开时沿用现有桌面隔离规则：桌面设置 `aria-hidden` 与 `inert`；场景关闭后必须解除。
- `Act2Experience` 应允许注入 `manager?: StateManager`，或提供等价的可隔离测试边界；不得直接访问 localStorage。

### 3. 资源空位

- 在 `data/images.json` 登记且仅登记本轮两个空位：
  - `IMG_A2_T02_001`：桥头调查场景占位，`act: 2`、`phase: A2_T02`、`file: null`。
  - `IMG_A2_T03_001`：县图书馆地方志书架占位，`act: 2`、`phase: A2_T03`、`file: null`。
- 桥头场景通用外层必须暴露 `data-asset-id="IMG_A2_T02_001"`；图书馆已有 `IMG_A2_T03_001` 标记，不得改内容组件。
- `src/imageAssets.css` 只提供克制的 CSS 占位，不伪装成正式美术；不得让 `file: null` 产生无效 URL 或网络请求。

### 4. 连续流程

必须可通过真实 UI 连续完成：

1. 第一幕结束页点击“回到桌面，继续调查”。
2. 桌面进入 `A2_T01/search`，保留第一幕 Flag、照片、浏览历史、笔记与窗口状态。
3. 在浏览器完成两类冻结查询（顺序任意），写入 T01 四个 Flag 与结论笔记并进入 `A2_T02/bridge`。
4. 桥头与普通老人交谈；只有向线索老人出示证据才出现“黑捕木”；完成三段字谜，获得县志提示；主动点击“去县图书馆查地方志”后进入 `A2_T03/library`。
5. 图书馆按“目录→卷册→逐叶翻页→至少 3 个核心词→主动摘录”完成，写入最终 Flag 和笔记，并停留在 T03 完成态；不得出现 T04 入口。
6. 在 T01、T02、T03 中重载均可续玩；清零后回到干净的第一幕阶段 A。

### 5. 自动验收

`src/story/act2T01T03.acceptance.test.ts` 至少覆盖：

- 第一幕完成门槛、第二幕启动与第一幕状态保留。
- T01 两类查询顺序任意、重复查询幂等、错误查询无推进、阶段和任务卡同步。
- T02 场景挂载、返回桌面/继续入口不丢状态、证据门槛、正确字谜与显式前往图书馆。
- T03 错误目录无推进、目标卷册不能跳页、核心词门槛、摘录完成、无 T04。
- schema 2 保存重载后从当前第二幕阶段恢复；清零完全移除第二幕状态。
- 桌面在场景打开时不可聚焦，返回桌面后恢复。

不要复制 WB-0002/0003/0004 的全部单元测试；本文件验证跨模块接线与连续状态链。

### 6. 离线验收

扩展 `scripts/verify-offline.mjs`，保留现有两轮第一幕 A–K、照片处理、存档重载和清零检查，并在至少一轮中继续完成第二幕 T01–T03。必须额外断言：

- 第二幕启动后第一幕状态仍在。
- T01 两类搜索后自动进入桥头。
- 桥头返回桌面与继续入口有效，证据/字谜/县志按钮按门槛出现。
- 图书馆只能逐叶到达目标页，少于 3 个核心词不能摘录，完成后无 T04。
- 第二幕阶段重载可恢复，最终清零后 `act2Research` 回到默认值。
- 单文件仍为经典内联脚本、零外部资源、零运行时错误。
