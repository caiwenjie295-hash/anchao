## 目标

把第三幕 T00–T07 的 59 个镜头改为以照片操作推进的调查。用户点击照片上的线索/方向，能放大、平移并切换视角；图片外只保留必要的说明与可访问性回退。构建可供第四幕 UX-0005 复用的无剧情状态依赖的照片探索组件。网页/软件调查不使用照片探索控件。

## 必须交付

1. 在 `src/components/PhotoViewport.tsx` 与独立样式中提供可复用照片探索视口：图片填充、点击放大/还原、缩放时拖拽平移、鼠标滚轮缩放、触控操作（至少单指拖动与双指缩放若设备支持）、键盘缩放/复位；限制缩放范围与平移边界，换镜头复位。互动热点与路线标记叠在图片内，随图变换仍可点击；视觉位置与交互目标分离以保证触控尺寸。
2. 第三幕 59 个已有 clue hotspot 全部有照片内可点位置。用独立视觉布局表按 lens ID/clue ID 记录归一化位置，不改剧情 JSON；线索若是声音、回忆等非实体，可在照片边缘用低调的听觉/回忆标记表示，不能伪造一个画面物体。所有镜头邻接路线均以照片边缘/画面内方向呈现；原有锁定条件和状态调用不变。
3. 镜头切换时，视角方向用轻微平移与放大衔接，必要时短暂淡黑；阶段切换可用黑色淡入淡出。避免长动画阻挡点击；在 `prefers-reduced-motion` 下立即切换。不得仅用通用页面跳转或卡片切换。
4. 探索层采用低饱和半透明磨砂玻璃：标题、场景说明、路线提示与一般操作；纸片原文、关键文档、强信息关联与必要提示可以使用不透明阅读层。第三幕原有并排纸片/神龛对照继续准确可读。
5. 把“检查全部线索”“继续下一段”等推进操作移进照片视口的轻量操作层，显著减少照片外按钮；保留键盘顺序、明确焦点、可关闭的线索详情及无图文字回退。
