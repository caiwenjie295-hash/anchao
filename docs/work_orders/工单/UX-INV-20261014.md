## 生图质量与空间约束

使用内置 imagegen，一资产一次调用；先 view_image 看每张本地参考。可按独立作业分批并发调用来提高速度，但任何引用前置新全景的作业必须在该全景验收后进行。原生输出复制和 WebP 编码属于素材落盘，不以滤镜／程序裁切替代生图。允许正确的压缩／尺寸优化，不用 Python 编辑内容或合成图片。

每个提示词明确禁止均匀鱼鳞／蜂巢／密集鳞片裂纹、过度浮雕颗粒。使用平滑大面积墙漆、稀疏自然大剥落、局部潮渍／锈斑，地面不过度刻纹。逐图复核不同机位、门窗左右、近远、楼梯上/下、纸片／胶带／卷盘与相邻图关系。近景是原机位向目标靠近，不是新房间；方向／声音类不凭空画声源；厨房不新增血肉或确定骨头来源。必须保留有意失焦的剧情意义。拒绝图必须重生，不把问题藏在 CSS 裁切里。

用户最新色彩要求：新生成图片降低饱和度，采用自然纪实／旧数码照片色彩，灰绿、灰蓝和褪色土黄，保持自然白平衡。避免鲜艳色块、浓重滤镜、HDR、霓虹和夸张橙青配色；地图同样克制褪色，黄色牌匾和旧排名纸保留辨识度但不过艳。未启动作业立即纳入完整提示词；已运行作业不取消或重复发送，先保存结果，最终统一验收时把明显过艳的候选集中重生。不得用程序滤镜代替生图编辑。

用户进一步要求降低**对比度**，达到类似普通手机摄影的超写实质感。以未修图的日常手机纪实照片为基准：自然中性白平衡、阴天／柔和日光或普通室内光、正常曝光、低饱和低对比、阴影柔和且保留细节，边缘可有适度手机镜头柔化或压缩质感，材质符合真实物理。不得把超写实误解为HDR或过度锐化；禁止电影调色、胶片滤镜、橙青配色、强局部清晰度、压黑阴影、戏剧性逆光、发光高光、插画或CG渲染质感。校园总图采用普通低空俯拍照片质感；纸张和黄色牌匾也按手机拍摄真实褪色实物。此要求优先于此前风格，已运行候选先落盘，最终集中处理明显高对比／渲染感的图。
