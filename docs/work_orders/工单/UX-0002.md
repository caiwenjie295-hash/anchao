## 目标

按主审视觉审查的四项建议改造前端：第四幕微博与邮箱、新闻/百科/论坛独立站点外观、第四幕照片接入后的画面呈现、全局转场入口与系统化文案。保持既有剧情、谜题答案、Flag、存档、资源 ID 与可玩流程。

## 必须交付

1. 第四幕 T03 的公开微博档案变成可信的账号资料和逐条动态流；T04 邮件变成可辨识的收件箱、邮件列表、阅读区。谜题仍嵌在真实操作语境中，不能只换皮保留两张大谜题卡。
2. 新闻、百科、论坛分别有清楚的站点品牌与信息架构。新闻呈现媒体栏目、作者/日期/相关内容；百科呈现目录、信息框、条目链接/来源区；论坛呈现楼层、用户、回复与社区导航。保留虚构站名，不使用真实平台 logo。
3. 第四幕 T01、T05、T06–T10 的图片通过稳定 `IMG_A4_*` 资源 ID 呈现；资源不存在时仍有可阅读的叙事回退，但玩家页面不显示“图片待补”“素材待接入”等制作字样。图片文件由另一工单 UX-0003 交付；你只写消费组件，不生成/编辑图片，不改资源注册表。
4. 去掉玩家可见的 `A4_Pxx`、`T00` 等内部编号与“内部索引”说法。第三幕顶栏可用地点/时间替代阶段号。
5. 将固定右下角“进行下一步调查”窗口替换为场景内入口。桌面阶段优先以记事本/任务栏的待办提示承载；浏览器内的下一步放入搜索结果内容流；返回桌面的恢复入口融入桌面或任务栏。不要用覆盖正文的大型悬浮卡。保留主动点击与原转场确认行为，不改变触发条件。
6. PC 宽屏与窄屏下检查主要页面可读性与遮挡；键盘焦点和语义标签可用。
