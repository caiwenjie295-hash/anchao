# 工单集中目录

这里集中存放已经冻结、完成或规划中的开发工单，便于按编号查看。

## 使用规则

- `docs/work_orders/README.md`：工单目录说明。
- `docs/work_orders/TEMPLATE.md`：新工单模板。
- 本目录下的编号工单由 Codex 主审冻结，执行 Agent 只读。
- 工单完成状态记录在 `docs/reviews/`，不回写工单正文。
- 第三幕规划稿位于 `第三幕_启明遗址开发计划/`；实际实施前仍需登记对应的 `A3-TXX.md` 冻结工单。
