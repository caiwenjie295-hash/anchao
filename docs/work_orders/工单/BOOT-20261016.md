## 冻结行为
1. HTML首屏内联黑底加载壳先于主JS/CSS可见，无白屏；细进度条/柔和白字，低动画偏好降级。模拟进度平滑单调，真实下载未全成功前不能到100或进入。文案不出现实现细节。失败有重试，不静默进入或无限假完成。
2. 生产构建自动生成版本资源清单，包含所有输出运行图片/JS/CSS/字体/小说和public文件，不包含源码/raw历史图片、node_modules、构建日志；HTML/清单/worker自身已随启动取得，不循环预加载。支持 /AnChao/ 和根路径，绝对不可硬编码根/assets。并发限制约4，按需读流/释放，不一次解码269张图占用大量内存。
3. 首次全下载；后续复用同版本资源缓存。优先实现同域作用域内的Service Worker+CacheStorage为预加载的资源提供实际缓存响应，版本切换避免混包，更新缓存仅限本游戏自己前缀，不接触localStorage/存档或其他站点。不能要求用户配置服务器或安装依赖。worker不缓存导航HTML/预加载清单，避免永久旧入口；路径严格同源/本base，缓存成功之后才计成功。注册更新/控制等待有限时，不支持的环境可下载预热HTTP缓存；任何下载失败不算完成。file离线版本直接正常启动，开发环境可直接进入或轻量演示，不要求获取不存在的生产清单。
4. 清零弹窗问题初步定位：组件目前渲染在taskbar内，taskbar backdrop-filter建立fixed包含块，确认层z100也低于taskbar9000。实际复现后最小修正：确认层portal到body，层级覆盖菜单与应用、box-sizing、最大高/滚动、窄屏/短屏按钮可见可点。若菜单本身越界，仅按实际需要修正；不全局改任务栏。保持隐藏在「其他选项」、默认取消、二次确认、Esc/Tab圈定与取消焦点返回、保存失败不清零。原resetProgress/Flag/schema/剧情语义不改。
