## 发布前性能观察

本批没有联网部署或测公网加载。保存的生产构建日志显示主 JS 为 1,019.17 kB、gzip 307.05 kB，离线包约 42 MiB；离线包体积不等同于在线首访下载。下一次上线前应在真实 URL 做新访客冷缓存和弱网实测，记录可操作首屏、首张关键照片与失败重试行为。若实测需要优化，优先考虑按应用/章节拆分代码、静态缓存与压缩，再按真实入口预取资源；不要无依据地预加载全部图片或统一降低素材质量。
