# 《暗潮》T07 桌面任务引导卡片交接

## 完成范围

第一幕桌面新增可折叠的“当前待办”调查便笺。卡片根据真实剧情 Flag 与照片编辑状态，依次引导玩家进入微信、邮箱、浏览器、资源管理器和照片应用；它只负责打开或聚焦应用，不会自动打开关键内容、写入 Flag 或推进阶段。

场景探索 G–I 仍由既有场景底部操作区引导。场景开启时桌面和卡片一起隐藏，第一幕完成后由幕末页取代桌面。

## 关键入口

- 引导文案与步骤：`data/task_guides.json`。
- 数据校验和当前任务求值：`src/data/taskGuideData.ts` 中的 `getCurrentTaskGuide(state)`。
- 卡片组件：`src/components/DesktopTaskCard.tsx`。
- 桌面接入：`src/App.tsx` 中的 `<DesktopTaskCard state={state} onOpenApp={openApp} />`。
- 视觉与响应式：`src/styles.css` 中的 `.desktop-task-card*`。

## 产品约束

- 宽屏默认展开；窄于 900px 时默认收起，均可手动切换。
- 卡片只显示当前调查组、组内完成进度和一个应用入口。
- 不显示确切搜索词、场景热点位置、照片滑杆数值或尚未发现的符号名称。
- 照片变清晰的完成判断复用 `isSymbolVisible`，不得在引导模块复制阈值。
- 卡片展开状态是临时 UI 状态，不进入存档。
