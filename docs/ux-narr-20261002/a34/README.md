# A34 定向验收入口

此本地 fixture 直接挂载真实的 `Act3Investigation` 与 `Act4NarrativeReader` 组件，不接入生产入口。入口加载正式的 `src/styles.css`；fixture 在动态导入状态管理器和场景模块之前替换 `window.localStorage`，并使用完全独立的内存 `Storage`，不会读写浏览器原存档。启动失败时会显示隔离错误并停止挂载。单元覆盖见 `fixtureStorage.test.ts`。每个模式都注入对应的合法当前阶段和前置完成状态；它用于定向检查，不代表从第一幕开始的全流程试玩。

在 A34 worktree 根目录执行：

```powershell
npm run dev -- --host 127.0.0.1
```

打开 `http://127.0.0.1:5173/docs/ux-narr-20261002/a34/fixture.html`，顶部固定工具栏会按实际高度为场景壳层留出空间，直接点击切换按钮访问：

- **A3 T07 · 回忆→观察**：从 T07_004 的小月回忆镜头开始，点击回忆热点，再走到蹲姿视角并检查取物顺序。
- **A4 T05 · 2014 亲历**：从“晚自习”开始，逐页阅读原文，检查场景图、逐页回顾、王澳视角边界和原文出处；生日、晚餐、带走回顾跟随对应语义页出现。
- **A4 T09 · 笔记→广播**：从王澳写回信后的合法章节状态开始，翻到原文块末尾，先藏好笔记，再走向门外查看整段广播。
- **A4 T10 · 结尾**：从 T10 当前状态开始，主动打开最后一封邮件、完成章节后再展开回顾。

fixture 只在内存中变更注入的 StateManager 状态，并拦截正式存档键的写入。可切换浏览器窗口宽度检查窄屏布局；浏览器最终抽查由本工单审查人执行。
